## Setup

### Create conda environment

```bash
conda env create -f environment.yml
```

### Activate the environment

```bash
conda activate tracker
```

### Deactivate the environment

```bash
conda deactivate
```

## Run

```bash
conda activate tracker
python video_tracker.py
```
